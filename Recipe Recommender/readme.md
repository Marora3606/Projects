# SmartChef

A recipe recommendation system that suggests recipes based on available ingredients, dietary preferences, and allergies.

## Features

- Recipe Recommendations
- Ingredient Matching
- Allergy Filtering
- Shopping List Generation

## Technologies

- Python
- Pandas

## Dataset

Recipes are loaded from a CSV dataset.

## Future Improvements

- AI Meal Planner
- Nutrition Analysis
- Streamlit Web App
- Voice Search
