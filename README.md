## 🛠️ Quick Setup & Environment

To create and activate a virtual environment for all projects:

```bash
cd /Users/user/Desktop/projects
python3 -m venv .venv
source .venv/bin/activate
```

To install dependencies for any individual project, navigate into its folder and run:
```bash
pip install -r requirements.txt
```
